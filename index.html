About Me

I am a graduate student in Applied Machine Learning at the University of Maryland, College Park. I am passionate about solving real-world problems using AI and building scalable, efficient ML systems that create meaningful impact. Prior to UMD, I served as a Founding Engineer at EyeZenX Analytics, where I designed a multimodal medical imaging pipeline that significantly improved diagnostic success rates, with a stakeholder patent held on the core architecture. I also worked as a Machine Learning Intern at Kaar Technologies, building production RAG systems that substantially reduced query latency and automated recruitment workflows.

My interests and current focus include:

  1. Agentic & Language-Centric AI:
    • Designing autonomous agents capable of planning, reasoning, and interacting with external tools and environments.
    • Developing generative AI applications with large language models and exploring LLM fine-tuning techniques such as instruction tuning, LoRA, and QLoRA for improved alignment, efficiency, and domain adaptation.
    • Building retrieval-augmented generation (RAG) pipelines to combine embeddings, vector databases, and generative reasoning, creating knowledge-grounded, reliable AI systems.
    • Focusing on applied NLP tasks such as summarization, information extraction, and question answering to transform unstructured text into actionable insights.
  2. Computer Vision & Multimodal Systems:
    • Exploring computer vision for image understanding, visual reasoning, and vision-language models.
    • Working on multimodal machine learning to integrate text, images, and audio into unified representations.
    • Aiming to develop AI systems capable of richer reasoning and perception, bridging visual and linguistic understanding for more general intelligent behavior.
  3. Data & Systems Engineering:
    • Designing scalable data pipelines and infrastructure to support modern machine learning workflows.
    • Includes dataset preparation, efficient data processing, and building deployment-ready systems for training and serving large-scale models.
    • Ensuring that research advances can be translated effectively into practical, production-ready AI solutions.

Projects
1.
CaseSage — AI System for Indian Legal Documents
Nov 2024 – May 2025
Longformer · NER · Neo4j · DeepSeek-v3 · FAISS · LSTM · RAGAS
Module 1 — Abstractive Summarization
Problem: Indian legal judgments frequently exceed 50,000 words, making manual review impractical and standard summarization models inadequate due to token limitations.
Solution: Implemented Longformer-based abstractive summarization, natively handling 16K+ token documents without truncation.
Improvement: Achieved a 50% improvement in ROUGE score over transformer baselines on domain-specific legal corpora.
Module 2 — Extractive Summarization via Entity Ranking
Problem: Abstractive summaries occasionally omit critical legal entities such as precedents, statutes, and case-specific terminology that practitioners depend on.
Solution: Designed an NER-based Entity Ranking pipeline using LSTMs to identify and surface key legal entities for extractive summarization alongside the abstractive output.
Improvement: Entity recall improved significantly, with summaries retaining all precedent citations present in the source document.
Module 3 — Precedent Retrieval via Knowledge Graphs
Problem: Keyword-based search fails to capture relational context between cases — a judge citing a case from 1987 may not use its exact title.
Solution: Constructed a Neo4j knowledge graph encoding case relationships, statutes, and judicial outcomes, enabling graph-traversal-based precedent lookup.
Improvement: Retrieval accuracy improved by 40% compared to BM25 keyword search on a held-out query set.
Module 4 — RAG-based Question Answering
Problem: Legal practitioners need to query specific clauses, rulings, or interpretations from large document collections in natural language — traditional search returns entire documents, not answers.
Solution: Integrated DeepSeek-v3 with a FAISS retrieval layer and RAGAS-based evaluation to deliver precise, citation-grounded answers to natural-language queries over the legal corpus.
Improvement: Reduced average lookup time by 65% relative to manual search, with RAGAS faithfulness scores consistently above 0.85.
2.
AutoCRM — Explainable Agentic CRM Automation
Jan 2025 – Apr 2025
CrewAI · GPT-4o-mini · Streamlit · LangChain · FastAPI
Problem: Conventional CRM automation tools act on customer data without providing reasoning — sales teams are unable to understand, audit, or override automated decisions, leading to low adoption and trust deficits.
Solution: Orchestrated a multi-agent B2C pipeline using CrewAI and GPT-4o-mini comprising four specialized agents: a scoring agent for customer prioritization, an outreach agent for personalized communication, a critic agent for self-correction, and a churn escalation agent — each outputting a written justification alongside every action. A Streamlit interface enables non-technical business users to adjust scoring weights, outreach tone, and agent behavior in plain language, dynamically rewriting system prompts without code changes.
Improvement: End-to-end customer outreach pipeline operates fully autonomously with complete decision traceability, reducing manual intervention in the CRM workflow and enabling non-technical stakeholders to configure and audit agent behavior independently.
3.
GraphMind — Agentic TensorFlow Debugger
Sep 2025 – Oct 2025
LangGraph · FAISS · NVIDIA Nemotron · ReAct · TensorFlow
Problem: Debugging deep learning pipelines is time-intensive — error messages are often cryptic, stack traces span multiple files, and the root cause frequently lies in tensor shape mismatches or configuration errors that static analysis tools cannot interpret in context.
Solution: Built an agentic debugging system that represents the codebase as a graph structure, retrieves semantically similar past error resolutions via FAISS, and uses NVIDIA Nemotron for code-level reasoning — all orchestrated by a ReAct (Reasoning-Action) agent that plans, executes, and observes iteratively. Self-learning feedback loops persist resolved error patterns, continuously expanding the retrieval corpus.
Improvement: Achieved a 45% improvement in debugging accuracy over static analysis baselines, with measurable reduction in mean time-to-resolution for common TensorFlow runtime errors.
