# Organization logos

Drop a logo here named after the entry it belongs to and it replaces the
monogram tile automatically on the next build. No code change needed.

| File name to use        | Shows next to                          |
|-------------------------|----------------------------------------|
| `fusionspan.svg`        | Software Developer Intern, fusionSpan  |
| `umd-clip.svg`          | Graduate Research Assistant, UMD       |
| `eyezenx.svg`           | Founding Engineer, EyeZenX             |
| `kaar.svg`              | Machine Learning Intern, Kaar          |
| `gemini-hack-night.svg` | Gemini Hack Night award                |
| `claude-architect.svg`  | Claude Certified Architect             |

`.svg`, `.png`, `.jpg` and `.webp` all work. Square artwork with a little
built-in padding looks best; the tile is 44px with the image contained inside.
Astro optimizes raster files at build time.
